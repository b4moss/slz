# v0.1.0 テスト仕様

スキャフォールドの受け入れ。自動テストの実装と CI は v0.2.0。本ファイルは検証内容の正本。

関連: [plans/v0.1.0/scaffold.md](../plans/v0.1.0/scaffold.md) / [main.md](../main.md)

前提:

- 入口は `go run ./cmd/slz`（または同等のビルド成果物 `slz`）
- バージョン文字列はハードコードの `0.1.0`
- cobra 既定の `--version` を使う。`-v` は対象外
- サブコマンド（`setup` / `config` / `mac` など）はまだ無い

---

### Execute

- cobra のルートコマンドを起動する
- `--version` が付いていればバージョンを標準出力に出して終了する
- バージョン表示以外のユースケースは実行しない

#### テスト：正常系
- `slz --version` の標準出力が `slz version 0.1.0`（末尾改行あり）である
- `slz --version` の終了コードが 0 である
- `slz --version` のとき標準エラーにバージョン文字列を出さない

#### テスト: 異常系
- 未知のフラグ（例: `slz --no-such-flag`）の終了コードが 0 でない
- 未知のサブコマンド（例: `slz nosuch`）の終了コードが 0 でない
- 引数なしの `slz` はバージョン行 `slz version 0.1.0` を標準出力に出さない
