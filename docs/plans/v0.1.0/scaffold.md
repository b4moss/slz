# v0.1.0 スキャフォールド

- **状態**: 仕様詳細
- **マイルストーン**: `v0.1.0`

開発の箱を先に作る。中身のユースケースはまだ入れない。検証内容は [tests/v0.1.0.md](../../tests/v0.1.0.md)。

## 含むもの

- [main.md](../../main.md) のディレクトリ構成どおりの箱。実ファイルが無くても **`.gitkeep` でよい**
- **Dev Container**（Go 1.26 系）が動き、その中で開発できる
- 手元スモーク: `go run ./cmd/slz --version` を叩き、次が出ること

```text
slz version 0.1.0
```

`go.mod` と `cmd/slz`（cobra で `--version` を出す最小の入口）は、スモークのために実ファイルが必要。バージョン文字列はハードコード。それ以外の `internal/` は空ディレクトリ + `.gitkeep` でよい（`internal/cli` に root を置く場合は実ファイル）。

## 含まないもの

- `setup` / `config` / `--help` / `mac dim`（[v0.2.0](../v0.2.0/usecases.md)）
- ユーザーコマンド、対話の本実装、`mv`、`doctor` など（v0.3.0 以降で再検討）
- 自動テストの実装と CI（v0.2.0）

## 開発環境

- 開発は **Dev Container**（Linux）で行う。コンパイルはコンテナ内
- Go は **1.26**（`go.mod` の言語バージョン）。パッチはコンテナ側で追う
- 実行ターゲットは **macOS のみ**（mac コマンドの確認はホスト。v0.1.0 では mac コマンド自体は無い）
- ディレクトリ構成の正本は [main.md](../../main.md)
